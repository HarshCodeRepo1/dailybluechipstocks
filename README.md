# Daily Blue Chip Stocks - V1

A React + TypeScript + Vite frontend for DailyBlueChipStocks.com.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

## Phase 1
- Responsive homepage
- Market summary
- Top 10 blue-chip watchlist
- Opportunity cards
- Sector spotlight
